🚗 Bluetooth-Controlled Arduino RC Car

Project Overview

This project involves designing and developing a Bluetooth-controlled robotic car using an Arduino UNO. The car can be controlled wirelessly through a mobile phone using Bluetooth communication.

This was my first hands-on electronics project, which helped me learn the basics of Arduino programming, motor control and hardware assembly.

Components Used

- Arduino UNO (SMD)
- DC geared motors
- Motor driver module
- Bluetooth module
- Four wheels
- Rechargeable batteries
- Battery holder
- Jumper wires
- DIY cardboard chassis

Working Principle

1. The mobile phone sends control commands through Bluetooth.
2. The Bluetooth module receives the commands.
3. Arduino UNO processes the received commands.
4. The motor driver controls the DC geared motors.
5. The car moves according to the commands received.

Features

- Wireless Bluetooth control
- Forward movement
- Backward movement
- Left and right turning
- Four-wheel drive arrangement
